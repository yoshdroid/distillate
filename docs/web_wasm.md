# Distillate Web/WASM Packaging Plan

## Goal

Distillate can be launched from a browser as a Pyxel Web app while keeping the desktop `python main.py` workflow unchanged.

The first milestone is a reproducible local build that creates:

- `web/distillate.pyxapp`: Pyxel app package
- `web/index.html`: browser-launchable HTML generated by Pyxel `app2html`

The second milestone is GitHub Pages publishing by committing `web/index.html` or attaching it to a release workflow.

## Chosen Approach

Use Pyxel's standard package flow:

```powershell
python -m pyxel package <app_dir> main.py
python -m pyxel app2html <pyxapp_file>
```

Distillate already has a clean `main.py` entry point and stage files are plain data under `distillate_stages/`, so no fork of the runtime code is needed for the initial Web build.

## Packaging Boundary

The Web package should include only runtime files:

- `main.py`
- `distillate/`

Stage data is embedded in `distillate/embedded_stages.py` for the Web build. The desktop build still prefers external files under `distillate_stages/`, and falls back to embedded data only when those files are unavailable.

Development notes, backups, Git metadata, caches, stage source files, and generated artifacts should stay outside the Web package. The build script stages a clean runtime tree under `build/pyxel-web-source/` before calling Pyxel.

When a stage `.dat` file changes, update `distillate/embedded_stages.py` before rebuilding the Web artifacts.

## Current Constraints

- Pyxel Web uses a generated HTML launcher that loads Pyxel's WASM runtime from CDN.
- Browser launch should be tested via a local HTTP server or GitHub Pages. Opening the file directly may work in some environments, but it is not the recommended acceptance check.
- The app uses `Path.cwd()` to find `distillate_stages/`. The package smoke test passed for package generation; browser execution still needs manual visual confirmation after serving `web/index.html`.

## Commands

Build the Web artifacts:

```powershell
.\scripts\build_web.ps1
```

Preview after build:

```powershell
python -m http.server 8000 -d web
```

Then open:

```text
http://localhost:8000/
```

## Acceptance Criteria

- `.\scripts\build_web.ps1` exits successfully.
- `web/index.html` exists and contains a Pyxel `launchPyxel` call.
- The title screen appears in a browser.
- Stage selection and game start work.
- Stage data loads from embedded Python data when `distillate_stages/` is unavailable.
